在 ZTools 主程序中添加平台、API key 和模型，再回到这里选择。凭据由 ZTools 管理。

数据如何处理

  • BibTeX 解析、统计和主题网络在本机完成，文件不会自动上传。
  • 使用在线模型时，分析内容会发给你选定的服务商；使用本地模型时按你的本地服务配置处理。
  • 划词翻译仅发送所选文字。在线语音生成发送当前英文句子；附带音频和录音在本机播放，录音不会自动上传。
  • 直连 AI 与翻译密钥保存在本机独立凭据文件中，重启可继续使用；可随时清除，题库备份不包含密钥。
  • 投稿助手不保存摘要、BibTeX 或分析历史；英语题库与学习记录通过 ZTools 插件存储保存，若宿主开启同步，请同时留意 ZTools 的同步设置。音频与录音保存在当前设备。关闭插件前请导出需要保留的结果。

通过 AI Agent 建题库

  1. 先在 ZTools 中开启 MCP 功能。在 ZTools 设置中找到 MCP，开启服务并查看连接配置。
  2. 将 ZTools 提供的连接配置添加到支持 MCP 的 AI Agent，确认能发现科研小盒的工具。
  3. 复制下方建库指令交给 Agent，再提供论文 PDF、网页链接或研究主题。Agent 整理后校验并保存课程。

使用 Agent 自身的模型与工具。保存完成后，返回自建素材库点击「刷新 MCP 题库」。
