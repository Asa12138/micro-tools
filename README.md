# 科研小盒（micro-tools）

科研常用小工具集合的 ZTools 插件。**纯 Preload（无构建步骤）**，可直接被 ZTools 以 `file://` 加载。

## 目录结构

```
micro-tools/
├── plugin.json              # 插件入口 + feature 触发配置
├── preload.js               # CommonJS：读两个数据集，合并后暴露 window.journalApi
├── index.html               # 前端界面（多功能 SPA）
├── index.css                # 样式
├── index.js                 # 前端逻辑
├── research.css             # 投稿助手、文献图谱与设置界面样式
├── research-core.js         # 本地 BibTeX 解析、统计、共现与候选召回
├── research-metrics.js      # 本地文献计量、SVG 图表与交互（插件 / 报告共用）
├── research-report.js       # 完整样式与脚本内嵌的独立 HTML 报告
├── research-prompts.js      # 可审阅的专业角色与 JSON 输出要求
├── research-service.js      # Preload 模型接口、会话 key 与协议适配
├── research-ui.js           # 两项新功能与设置的交互逻辑
├── journals.json.gz         # JCR 2026 期刊数据（22,643 条，gzip -9）
├── ccf.json.gz              # CCF 第七版目录（677 条，gzip -9）
├── pack.sh                  # 打包为 .zpx（ASAR + brotli）
├── logo.png / logo.svg      # 插件图标
└── README.md
```

| 功能 | 状态 | 说明 |
| --- | --- | --- |

| **投稿助手** | 新增 · 公开试用 | 自带角色提示词，摘要画像、高亮、期刊匹配与投稿准备建议 |
| **文献图谱** | 新增 · 公开试用 | 年度趋势、期刊 / IF、作者生产与合作、共词网络和热图 |
| **数据库查询** | 🔧 体验版 | NCBI / PubMed / UniProt / PDB / Ensembl 等一键检索 |
| 单位换算 | 🚧 即将推出 | 科研常用单位 |

### 期刊 · 会议查询

一个入口同时检索两套体系，卡片上**有就显示、没有就不显示**：

| 数据 | 来源 | 卡片显示 |
| --- | --- | --- |
| 影响因子 / 分区 / JCI / 被引 | JCR 2026（22,643 条） | `IF 20.4`、`Q1`、四项统计 |
| CCF 等级 / 领域 / 变动 | CCF 第七版（677 条） | `CCF A`、`人工智能`、`晋级` |

- **三种情况都覆盖**：既有 IF 又有 CCF 等级（如 TPAMI：IF 20.4 + CCF A）；只有 CCF 等级（会议，如 CVPR；以及已被 JCR 除名的期刊，如 MTA）；只有 IF（非计算机领域期刊，如 Nature）。
- 检索字段：期刊/会议全称、JCR 缩写、**CCF 缩写**、ISSN、CCF 中文领域（可直接搜「人工智能」）。
- 顶部筛选条：**全部 / 期刊 / 会议**。
- 动作按钮：复制信息（纯文本多行）、JCR 官网、官方主页/DBLP。
- 相关性排序：精确 > 前缀 > 包含，同分按影响因子降序。

### 数据库查询

输入检索词 → 选择数据库 → 系统浏览器打开检索结果（`ztools.shellOpenExternal`）。
支持：NCBI Genome / Gene / Nucleotide、PubMed、UniProt、PDB、Ensembl、Google Scholar。

### 投稿助手（本次新增）

首页第 2 张卡片。标题可留空，摘要须为 80–18000 字符。稿件类型默认由模型判断，也可手动指定；投稿偏好与预期 IF 范围均可选，“包含综合期刊”默认勾选。

1. AI 提取研究画像、亮点、摘要高亮和信息缺口。高亮须与原文逐字匹配。
2. 用期刊名称线索和英文领域词（含详细学科分类）召回本地 JCR / CCF 期刊候选，最多 65 本。为 Nature、Science、Nature Communications、Science Advances、PNAS 等真实综合刊保留比较位置。取消勾选则排除综合刊；IF 上下界同样约束所有候选，缺失值不当作 0。
3. AI 只能选取候选记录 ID，目标为 4–6 本，缺乏适配依据时允许更少。程序过滤未知/重复 ID，期刊名称与指标来自本地库。模型逐一解释综合刊入选或未优先推荐的依据，不保证高 IF 刊入选。

建议卡片包含出版方、ISSN、学科、JIF 数据年与分区、匹配理由、潜在问题、须核实的投稿条件，以及官网指南与投稿经验的**外部检索入口**。本版不自动抓取最新作者指南、APC 或第三方评价，也不估计录用概率。可导出 HTML 报告（浏览器中可打印为 PDF）。

研究画像与摘要高亮放在期刊推荐前，各章节可折叠。期刊卡片突出名称、出版方、JIF / 分区 / 具体学科、内容适配与投稿前关注项。最优候选后附本轮粗筛清单：可按名称 / ISSN / 出版方、学科、综合 / 专科类别与 IF 筛选，支持排序与分页。粗筛入围不等于建议投稿。侧边悬浮导航点击时展开目标章节；窄窗口收为浮动按钮。分析完成后自动定位到结果。交流入口区分 [Springer Nature 官方 Research Communities](https://communities.springernature.com/amp/posts/a-quick-guide-to-navigating-the-communities)、[INASP Rising Scholars / 原 AuthorAID 讨论组](https://risingscholars.net/en/discussion/) 与 [PubPeer 独立非营利发表后评议](https://pubpeer.com/static/about)，不把第三方评论标成期刊官方意见。

HTML 导出内嵌 `index.css` 与 `research.css` 的完整样式及导航 / 粗筛表格的交互代码，无外部字体或运行资源依赖；链接、原文高亮与全部建议均保留，各章节默认展开。粗筛筛选恢复默认，完整候选保留在报告中；打印时展开章节并显示全部候选。无需 ZIP 解压即可打开，内置打印 / 保存 PDF 按钮。报告不会包含 API key 或模型配置。

期刊匹配无需联网，插件不设置自己的中转服务器。AI 分析仍按接入方式调用直连 API 或 ZTools AI；使用在线模型会将研究内容发送至相应服务，不能宣称全程不联网或绝无泄密。使用本机模型可避免外部模型调用；外部网站仅在用户点击入口时打开。

角色与结构化输出约束可直接审阅 `research-prompts.js`。模型错误、无效 JSON、未核对高亮/候选不会当作已验证内容展示；推荐阶段失败时保留已完成的摘要画像。

### 文献图谱（本次新增）

首页第 3 张卡片。支持选择/拖入 `.bib`（≤ 8 MB、≤ 3000 条），解析嵌套大括号、引号、宏拼接、常见 LaTeX 字符及作者列表。

- 本地统计年代、期刊/载体、综述/研究论文/其他/待确认类型和元数据缺口。
- 主题图按标题与关键词共现生成，连线阈值为至少 2 条；**不代表引用关系**。支持放大/适应与横向滚动；点击年份、期刊或节点筛选，支持检索、分页、人工修改类型。
- `@article` / `@misc` 不用于强制判断研究论文。明确类型字段优先；标题线索、可选 AI 分类均标注来源与待复核状态，人工指定优先。
- AI 分类是用户主动触发的独立动作，按每批 20 条提交标题、已有摘要（截取至 2400 字符）、类型字段；不提交作者名单或完整文件。取消/失败保留已完成批次。
- 支持 CSV 与完整 HTML 报告导出。没有期刊、DOI、摘要时显示缺失，不补造。

四组交互计量视图（在本机独立实现，参考 [Bibliometrix](https://www.bibliometrix.org/) 与 [VOSviewer 文档](https://www.vosviewer.com/documentation) 的分析类型）：

| 视图 | 方法与交互 |
| --- | --- |
| 概览趋势 | 论文类型堆叠年度柱形 / 累计曲线、期刊频率及期刊 × 年份热图 |
| 期刊与 IF | JIF 匹配覆盖率、直方图与五数概括、发表年份 × JIF 散点；按区间或单条文献筛选 |
| 作者分析 | 作者频率（完整计数 / 每篇 1/n 分数计数）、作者 × 年份热图；点击作者筛选 |
| 关系网络 | 合著 / 共词网络，确定性弹簧布局；节点上限、共同文献阈值、完整 / 分数连线、连通分量 / 平均年份颜色、缩放 / 拖动平移与邻居高亮 |

类型选择同时改变图表范围与清单。年份、载体、作者、词项、JIF 区间与文献点可组合筛选；热图单元格联动名称和年份。图形筛选保留当前类型范围的全景，清单显示符合条件的条目。

JIF 仅按 ISSN 或名称 / 库内缩写的唯一标准化精确匹配（忽略大小写、标点与首部 `The`）。不猜测不确定别名；缺失不按 0 计。**所有年份的文献映射至同一本地 JCR 快照的 2025 JIF，不能解释为历史 IF，也不能作为单篇论文质量指标。** 直方图按文献条目计数，重复出现的期刊会按其文献频率贡献。

作者计数每篇去重，排除 `others` / `et al` 占位符，保留名称顺序与变音符号；没有 ORCID / 机构时不确认作者身份，同名异人、同人不同缩写均可能影响统计。作者产出分数每篇为 `1/n`；合著连线分数每篇为 `1/(n−1)`（[完整与分数网络计数方法](https://arxiv.org/abs/1607.02452)）。阈值始终按共同文献条数；最多绘制前 80 个节点、最强 240 条达阈值连线，完整范围的频率统计不截断。颜色表示显示子图的连通分量或节点平均年份，不声称自动识别学科团队。缺引文信息时不计算共被引、文献耦合、被引量或 h-index。

文献 HTML 报告内嵌完整 CSS、SVG 生成脚本与最小必要数据，共用插件图表组件，离线支持四组视图、筛选、缩放平移与完整表格检索。CSV 增加匹配 JIF、数据年、匹配方法及状态。报告包含文献名称与作者等导出内容，请按需要分享；不会包含本地附件路径、API key 或原始 BibTeX 全文件。

### 模型与 API 设置

右下角设置按钮始终可用。两项功能共用配置：

**推荐方式：**在 ZTools 主程序配置模型，然后选“使用 ZTools 已配置的 AI”。插件通过 [`ztools.ai` 与 `allAiModels`](https://ztoolscenter.github.io/ZTools-doc/ai-api.html) 调用；需要宿主提供这些接口。旧版宿主可改用直连。

**直连方式：**选择预设 → 按官方配置文档获取 key、Base URL 和模型 ID → 保存并测试。提供 DeepSeek、阿里云百炼、硅基流动、Moonshot/Kimi、OpenAI、Anthropic、Gemini 与 Ollama 预设及自定义 OpenAI 兼容地址。百炼模板须替换业务空间 ID，并确认地域。模型参数/权限随平台变化，预设不保证所有模型都支持。

协议：OpenAI Chat Completions、Anthropic Messages、Gemini GenerateContent。直连由 Node Preload 发起，避免浏览器 CORS 限制；远程地址强制 HTTPS，本机 localhost 可用 HTTP；不跟随重定向转发凭据。支持连接测试、取消、180 秒超时、响应大小限制和错误提示。

**隐私范围：**BibTeX 本地分析无需联网。在线 AI 会接收用户提交的分析内容，服务商的数据政策仍适用；自己的 API key 不等于绝对无泄密。插件直连 key 仅保存在本次插件进程内存，重新加载后重新填写；ZTools 管理的凭据遵循宿主的保存策略。只有模式/地址/模型等非敏感设置经 `dbStorage` 保存，不保存摘要、BibTeX 或分析历史。Ollama 可作为本机模型方案。

当前版本 **1.4.0**。本次新增功能面向 ZTools 端；浏览器扩展与小程序仅同步版本号，共享期刊检索算法及数据保持不变。安装包与更新说明见 [GitHub Releases](https://github.com/Asa12138/micro-tools/releases)。插件中心版本以审核合并状态为准。

## 数据合并机制

`preload.js` 加载时把 CCF 目录按 ISSN 关联到 JCR 期刊：

- 关联成功（277/291 条 CCF 期刊，95.2%）→ CCF 字段挂到该 JCR 记录上，并把 CCF 缩写并入检索词表，**一张卡同时显示两套指标**。
- 未关联（386 条会议 + 14 条未被 JCR 收录的期刊）→ 作为独立记录并入统一检索数组，只显示 CCF 等级。

CCF 中跨领域重复收录的刊物（如 TOMM 同时挂「网络」和「图形学」）会合并为一条，领域显示为 `网络 · 图形学`。

## 数据源

- **JCR**：`2026年度JCR期刊名单（完整版）.xlsx` → 转换压缩为 `journals.json.gz`（短键名 + gzip -9，1.6 MB）。22,643 条，含 2025 JIF / 分区 / JCI 等字段。
- **CCF**：《中国计算机学会推荐国际学术会议和期刊目录》第七版（2026 年 3 月发布）→ `ccf.json.gz`（19.9 KB）。677 条 = 291 期刊 + 386 会议，分 A/B/C 三级、10 个领域方向。
- 两个数据集均为静态快照，更新时替换对应 `.gz` 文件即可（`pack.sh` 会自动打包）。

## 在 ZTools 中使用

1. 插件管理 → 添加本地插件，选择 `micro-tools/` 目录（或导入 `micro-tools-vX.Y.Z.zpx`）。
2. 搜索框输入：
   - `科研小盒` / `kyxh` — 打开工具箱首页
   - `期刊 Nature` / `影响因子 JACS` — 进入期刊·会议查询
   - `ccf CVPR` / `会议 NeurIPS` — 直接进入并切到「会议」筛选
   - `数据库 BRCA1` — 进入数据库查询
   - `投稿助手` / `文献图谱` / `科研小盒设置` — 进入本次新增功能
3. 划词后通过 `type: over` 触发「查询期刊/会议」，自动带入选中文本。
